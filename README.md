# Toxic Skill Club — бронирование ПК в Telegram

Telegram-бот + мини-приложение для компьютерного клуба:

- 🗺 карта всех ПК по зонам с живыми статусами: **«Свободен»**, **«Свободен до 19:00»**,
  **«Занят до 18:45 · ещё 1 ч 12 мин»**, **«Ваш ПК»**;
- ⏱ время выбирается **с точностью до минуты**: лента-линейка, кнопки ±1 мин (удержание — быстрее),
  пресеты и точное время через системные часы;
- 🚦 занятое время видно прямо на ленте, при пересечении приложение подсказывает, как исправить;
- 💰 цена считается поминутно и видна на кнопке «Забронировать · 633 ₽»;
- 👤 «Мои брони» с обратным отсчётом, продлением и отменой;
- 🔔 подтверждение брони, напоминания за 15 минут до начала и за 10 минут до конца
  (с кнопками «продлить»), уведомления админам о каждой брони;
- 🛡 вход только через подпись Telegram; админы видят, кто занял ПК, и могут освободить любой.

## 🚀 Быстрый старт (Windows)

1. **Python.** Скачайте Python 3.12 с [python.org](https://www.python.org/downloads/) и при установке
   **поставьте галочку «Add python.exe to PATH»**.
2. **Бот.** Если бота ещё нет — в Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
3. **Запуск.** Дважды щёлкните **`start.bat`** в папке проекта.

При первом запуске откроется мастер настройки — он сам создаст файл `.env`:

| Шаг | Что делать |
|---|---|
| 1. Токен | @BotFather → `/mybots` → ваш бот → **API Token** → скопировать и вставить в окно |
| 2. Админ | открыть своего бота в Telegram и нажать **«Старт»** — мастер сам запомнит вас как админа |
| 3. Интернет | **Enter** (Cloudflare, без регистрации) или **2** (tuna.am, серверы в России) |
| 4. Страница | **Enter** |

Готово: в окне появится «✅ Бот работает», а вам в Telegram придёт сообщение «🟢 Бот запущен»
с кнопкой бронирования. Кнопка **«🎮 Бронь»** есть и слева от поля ввода у всех клиентов.

> Окно с ботом должно оставаться открытым — пока оно открыто, бронирование работает.
> Пройти настройку заново: `start.bat --setup`.

На Linux/macOS всё то же самое через `./start.sh`.

## 🌐 Как клиенты попадают к боту

Бот работает на вашем компьютере, а клиентам нужен адрес в интернете. Бот поднимает его сам:

- **Cloudflare** (по умолчанию) — бесплатно, без регистрации, программа скачивается автоматически.
  ⚠️ В России провайдеры с 2025 года замедляют Cloudflare, у части клиентов страница может не открываться.
- **tuna.am** — серверы в Москве. Нужна бесплатная регистрация на [tuna.am](https://tuna.am), токен берётся на
  [my.tuna.am/token](https://my.tuna.am/token). Мастер предложит установить программу tuna сам.
- **Свой адрес** — если есть VPS или домен: в `.env` укажите `TUNNEL=off` и `PUBLIC_URL=https://...`.

Адрес туннеля меняется при каждом запуске — бот сам обновляет кнопку «🎮 Бронь». Если связь пропадёт,
бот переподключится и напишет админу.

### Vercel

Страница бронирования может открываться с Vercel (`https://toxic-skill.vercel.app`) — так она грузится быстрее.
Vercel публикует ветку `main`, поэтому новая версия появится там после слияния изменений в `main`.
Пока на Vercel старая страница, бот это замечает и показывает страницу прямо со своего адреса — всё работает и так.

## ⚙️ Настройка клуба

Цены, зоны и номера ПК — в `config.py` (откройте Блокнотом):

```python
ZONES = (
    Zone("standard", "Standard", 150, "RTX 4060 · i5-13400F · 165 Гц", "#39ff14"),
    Zone("vip", "VIP", 250, "RTX 4070 Super · i7-14700F · 240 Гц", "#c44dff"),
)
ZONE_LAYOUT = {
    "standard": range(1, 16),   # ПК 1–15
    "vip": range(16, 22),       # ПК 16–21
}
```

После правки перезапустите бота. Там же правила: мин./макс. длительность (30 мин – 12 ч),
шаг ползунков (`BOOKING_STEP_MIN = 1` — поминутно), горизонт бронирования (48 ч),
лимит активных броней на клиента (3, у админов без лимита).

Клиенты «с улицы»: админ открывает приложение и бронирует ПК на себя — для админов лимитов нет,
и все видят, что ПК занят и до скольки.

## Команды бота

`/start` — открыть бронирование · `/my` — мои брони · `/status` — какие ПК свободны и до скольки заняты ·
`/bookings` — все брони (только админы).

## Для разработчика

| Файл | Что внутри |
|---|---|
| `bot.py` | точка входа: бот + API + туннель + напоминания |
| `setup_wizard.py` | мастер первой настройки (создаёт `.env`) |
| `tunnel.py` | cloudflared / tuna, автоскачивание и автопереподключение |
| `config.py` | настройки клуба и правила |
| `services.py` | логика броней: пересечения, продление, отмена, статусы |
| `storage.py` | SQLite |
| `webapi.py` | HTTP API для WebApp, проверка подписи Telegram |
| `handlers.py` | команды, кнопки, уведомления, напоминания |
| `index.html` | WebApp (один файл, без сборки) |

```bash
pip install -r requirements.txt
python -m unittest discover -s tests        # тесты
DEV_MODE=1 python bot.py --no-polling       # только API + страница на http://127.0.0.1:8080
```

Все настройки `.env` описаны в `.env.example`. `DEV_MODE=1` пускает в API без Telegram — **не включайте его в работе**.

## Что можно улучшить дальше

1. **VPS в России** (от ~200 ₽/мес) — бот работает 24/7 с постоянным адресом, без туннеля и включённого ПК.
2. **Предоплата** через Telegram Payments / ЮKassa — меньше «неявок».
3. **Интеграция с системой управления клубом** (Langame, SENET, SmartShell) — реальная занятость ПК без ручного ввода.
4. Статус «на обслуживании», ночные пакеты, бонусы за посещения.
5. Ежедневная копия файла `club.db` (все брони хранятся в нём).
