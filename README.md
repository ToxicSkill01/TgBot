# Toxic Skill Club — бронирование ПК в Telegram

Telegram-бот + WebApp для компьютерного клуба:

- 🗺 карта всех 21 ПК по зонам (Standard / VIP) с живыми статусами:
  **«Свободен»**, **«Свободен до 19:00»**, **«Занят до 18:45 · ещё 1 ч 12 мин»**, **«Ваш ПК»**;
- ⏱ выбор времени **с точностью до минуты**: лента-линейка для начала и длительности,
  кнопки ±1 мин (удержание — быстрее), быстрые пресеты, точное время через системный пикер;
- 🚦 занятые интервалы видны прямо на ленте, конфликт подсвечивается и предлагается исправление
  («Сократить до 19:00», «Ближайшее свободное окно»);
- 💰 цена считается поминутно и видна на кнопке «Забронировать · 633 ₽»;
- 👤 «Мои брони» с обратным отсчётом, продлением и отменой;
- 🔔 бот присылает подтверждение, напоминает за 15 минут до начала и за 10 минут до конца
  (с кнопками «продлить на 30 мин / 1 ч / 2 ч»), админы получают уведомления о каждой брони;
- 🛡 вход только через подпись Telegram (`initData`), админы видят, кто занял ПК, и могут освободить любой.

## Как это устроено

```
Telegram ──► бот (aiogram, polling)          ┐
WebApp (Vercel) ──► HTTPS-туннель ──► API (aiohttp) ┤  один процесс python bot.py
                                     SQLite (club.db) ┘
```

| Файл | Что внутри |
|---|---|
| `bot.py` | точка входа: бот + API + напоминания |
| `config.py` | настройки: зоны, цены, номера ПК, правила бронирования |
| `services.py` | логика броней: проверка пересечений, продление, отмена, статусы |
| `storage.py` | SQLite |
| `webapi.py` | HTTP API для WebApp, проверка подписи Telegram |
| `handlers.py` | команды бота, кнопки, уведомления, напоминания |
| `index.html` | WebApp (один файл, без сборки) |

## Установка

Нужен Python 3.10+.

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | Telegram id админов через запятую (свой id подскажет [@userinfobot](https://t.me/userinfobot)) |
| `PUBLIC_URL` | публичный **https**-адрес бота (туннель, см. ниже) |
| `WEBAPP_URL` | адрес WebApp на Vercel, например `https://toxic-skill.vercel.app`. Пусто — страницу отдаёт сам бот |
| `CLUB_TZ` | часовой пояс клуба, по умолчанию `Europe/Moscow` |

> ⚠️ Токен храните только в `.env`. Если токен когда-либо попадал в git или на Vercel —
> перевыпустите его в @BotFather (`/revoke`).

### Публичный адрес для бота на своём ПК

WebApp на Vercel должен как-то достучаться до бота у вас дома. Проще всего — туннель
[Cloudflare](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/):

```bash
cloudflared tunnel --url http://localhost:8080
```

Он напечатает адрес вида `https://xxxx.trycloudflare.com` — впишите его в `PUBLIC_URL` и перезапустите бота.
Бот сам передаёт этот адрес в WebApp (`?api=...`), поэтому **передеплоивать Vercel при смене адреса не нужно**.

Быстрый туннель меняет адрес при каждом запуске. Чтобы адрес был постоянным — именованный туннель
Cloudflare со своим доменом или статический домен ngrok (`ngrok http --url=имя.ngrok-free.app 8080`).

### Vercel

Vercel публикует `index.html` из корня репозитория, как и раньше. Файл `.vercelignore` не пускает
туда код бота, `.env` и базу. Можно обойтись и без Vercel: оставьте `WEBAPP_URL` пустым — тогда
WebApp откроется прямо с `PUBLIC_URL`.

## Запуск

```bash
python bot.py
```

При старте бот сам настраивает команды и кнопку меню «🎮 Бронь» рядом с полем ввода.

Команды: `/start` — открыть бронирование, `/my` — мои брони, `/status` — какие ПК свободны и до скольки
заняты, `/bookings` — все брони (только админы).

## Настройка клуба

Всё в `config.py`:

- `ZONES` — названия, цены за час, железо, цвета зон;
- `ZONE_LAYOUT` — какие номера ПК в какой зоне;
- `MIN_BOOKING_MIN` / `MAX_BOOKING_MIN` — мин./макс. длительность (сейчас 30 мин – 12 ч);
- `BOOKING_STEP_MIN` — шаг ползунков (1 = поминутно, можно 5 или 15);
- `HORIZON_HOURS` — насколько вперёд можно бронировать (48 ч);
- `MAX_ACTIVE_PER_USER` — сколько активных броней у одного клиента (у админов без лимита).

Клиенты «с улицы»: админ открывает WebApp и бронирует ПК на себя — для админов лимитов нет,
так все сразу видят, что ПК занят и до скольки.

## Разработка и тесты

```bash
python -m unittest discover -s tests        # тесты логики и API
DEV_MODE=1 python bot.py --no-polling       # только API + страница на http://localhost:8080
```

`DEV_MODE=1` пускает в API без Telegram (тестовый пользователь) — **не включайте его в работе**.

## Что ещё можно улучшить

1. **Перенести бота на VPS** (от ~200 ₽/мес) — бронь работает 24/7, не зависит от включённого ПК и туннеля.
2. **Предоплата** через Telegram Payments / ЮKassa — меньше «неявок».
3. **Интеграция с системой управления клубом** (Langame, SENET, SmartShell и т. п.) — реальная занятость
   ПК без ручного ввода посетителей «с улицы».
4. Статус **«на обслуживании»** для ПК, ночные пакеты и скидки, бонусы за посещения.
5. **Бэкапы** `club.db` (достаточно копировать файл раз в день) и мониторинг доступности.
6. При росте нагрузки — PostgreSQL вместо SQLite.
